====== SetBitmapMode ======

Set Bitmap Mode (set bit #5 of $d011).

| SYNTAX:     | :SetBitmapMode |
| EXAMPLE:    | :SetBitmapMode |
| PARAMETERS: |  N/A           |

<code>
    .pseudocommand SetBitmapMode {
        lda #%0010000000000000
        tsb $d010
    }
</code>

====== Keyboard Routine V3.0 ======

===== What's new =====

Basically a lot of improvements in terms of size and speed, basic functionality intact. The
routine utilizes SMC, so any ROM adaptation has to take this into account.

Major new feature is return of repetitive keys when a key is being held down along with an
initialization routine to set timers to control this. NB! This is only valid for Alpha-numeric
keys for now, Non-Alpha-Numeric [INST/DEL, C=, SHIFT, ...) are returned as flags in X/Y register.

There are still features I'd like to implements (parameter controlled repeat keys of CRSR and
RETURN keys f.ex), and parameter controlled return of Alpha-Numeric Keys in conjunction with
SHIFT and C= for example. But for now the user must take care of this.

I also included the test tool source which has been developed somewhat as well.


===== Source Code for the Keyboard Routine =====

<code>
    /*=============================================================================================
      Keyboard IO Routine                                                               By: TWW/CTR
      -------------------
        
      Information:

        Uses "2 Key rollover" or up to 3 if the key-combination doesen't induce shadowing.
        If 2 or more keys are pressed simultaneously (within 1 scan) a "No Activity" state has to
        occur before new valid keys are accepted.
        RESTORE is not detectable and must be handled by NMI IRQ.
        SHIFT LOCK is not detected due to unreliability.

      How to use example:

            jsr Keyboard
            bcc !NoError+
                // Handle errors
        !NoError:
            sta $0400  // Alphanumeric Keys (#$ff => same key(s) pressed, no new key)
            stx $0401  // Non-Alphanumeric Keys #1
            sty $0402  // Non-Alphanumeric Keys #2

      Returned:

        +===============================================================================+
        |                            Returned in Accumulator                            |
        +=========+=========+=========+=========+=========+=========+=========+=========+
        | $00 - @ | $08 - h | $10 - p | $18 - x | $20 -   | $28 -   | $30 - 0 | $38 - 8 |
        | $01 - a | $09 - i | $11 - q | $19 - y | $21 -   | $29 -   | $31 - 1 | $39 - 9 |
        | $02 - b | $0a - j | $12 - r | $1a - z | $22 -   | $2a - * | $32 - 2 | $3a - : |
        | $03 - c | $0b - k | $13 - s | $1b -   | $23 -   | $2b - + | $33 - 3 | $3b - ; |
        | $04 - d | $0c - l | $14 - t | $1c - £ | $24 -   | $2c - , | $34 - 4 | $3c -   |
        | $05 - e | $0d - m | $15 - u | $1d -   | $25 -   | $2d - - | $35 - 5 | $3d - = |
        | $06 - f | $0e - n | $16 - v | $1e - ^ | $26 -   | $2e - . | $36 - 6 | $3e -   |
        | $07 - g | $0f - o | $17 - w | $1f - < | $27 -   | $2f - / | $37 - 7 | $3f -   |
        +---------+---------+---------+---------+---------+---------+---------+---------+

        +================================================================================
        |                             Return in X-Register                              |
        +=========+=========+=========+=========+=========+=========+=========+=========+
        |  Bit 7  |  Bit 6  |  Bit 5  |  Bit 4  |  Bit 3  |  Bit 2  |  Bit 1  |  Bit 0  |
        +---------+---------+---------+---------+---------+---------+---------+---------+
        | CRSR UD |   F5    |   F3    |   F1    |   F7    | CRSR RL | RETURN  |INST/DEL |
        +---------+---------+---------+---------+---------+---------+---------+---------+

        +================================================================================
        |                             Return in Y-Register                              |
        +=========+=========+=========+=========+=========+=========+=========+=========+
        |  Bit 7  |  Bit 6  |  Bit 5  |  Bit 4  |  Bit 3  |  Bit 2  |  Bit 1  |  Bit 0  |
        +---------+---------+---------+---------+---------+---------+---------+---------+
        |RUN STOP | L-SHIFT |   C=    | R-SHIFT |CLR/HOME |  CTRL   |         |         |
        +---------+---------+---------+---------+---------+---------+---------+---------+

        CARRY:
          - Set = Error Condition (Check A for code):
              A = #$01 => No keyboard activity is detected.
              A = #$02 => Control Port #1 Activity is detected.
              A = #$03 => Key Shadowing / Ghosting is detected.
              A = #$04 => 2 or 3 new keys is detected within one scan
              A = #$05 => Awaiting "No Activity" state
          - Clear = Valid input
              A =  #$ff => No new Alphanumeric Keys detected
                           Some key(s) being held down AND/OR
                           Some Non-Alphanumeric key is causing valid return
              A != #$ff => New Alphanumeric Key returned.
                           Non-Alphanumeric keys may also be returned in X or Y Register

      Speed / Size
        - See KeyboardTest.asm

             │ Yes

    .pc = * "Keyboard Scan Routine"


    // ZERO PAGE Varibles
    .const ZP_ScanResult               = $50     // 8 bytes - Holds Raw IO data from keyboard scan
    .const ZP_ScanKeyBuffer            = $58     // 3 bytes - Holds keys found during a valid scan
    .const ZP_Temp                     = $5b     // 1 byte  - Holds temporary values
    .const ZP_FLAG_NewKeyScanOverflow  = $5c     // 1 byte  - Flag - waiting for no activity state
    .const ZP_NonAlphaFlagX            = $5d     // 1 byte  - Flag - Non-Alphanumerik Keys Detected
    .const ZP_NonAlphaFlagY            = $5e     // 1 byte  - Flag - Non-Alphanumerik Keys Detected
    .const ZP_RepeatFlag               = $5f     // 1 byte  - Flag - Repeat keys allowed
    .const ZP_RepeatTimer              = $60     // 1 byte  - Timer Value
    .const ZP_Temp2                    = $61     // Temp Value

    // Operational Variables
    .const MaxKeyRollover              = 3

    // Error Codes
    .namespace ERROR {
        .label NoActivity              = 1       // No activity from Control Port at all
        .label CtrlPortActivity        = 2       // Game Port Activity Detected
        .label Shadowing               = 3       // More than 3 keys pressed simultaneously
        .label KeyScanOverflow         = 4       // More than 1 new key found in one scan
        .label KeyScanOverflowFlag     = 5       // Impossible to determine which was First,
                                                 // only cleared by a "No Activity" flag clear.
    }


    //---------------------------------------------------------------------------------------------
    // Keyboard Initialization
    //
    // Configures Data Direction Registers
    // Configures Repeat Flag & Timer
    //
    // Parameters:
    //   Accumulator: Postive  = Allow Repeat Keys
    //                Negative = Don't allow Repeat Keys
    //   X-Register:  Repeat Key Timer (duration to routine to report a held key again)
    //---------------------------------------------------------------------------------------------


KeyboardInit:

    //-------------------------------------------
    // Setup Repeat Flag & Timer
    //
    // The flag is used to determine if an alpha-
    // Numeric key shall be repeated when being
    // held down. Timer1 is the initial delay,
    // Timer2 is the consecutive repetitions.
    //-------------------------------------------

    sta ZP_RepeatFlag
    stx ZP_RepeatTimer
    stx SMC_RepeatTimer1
    sty SMC_RepeatTimer2

    //-------------------------------------------
    // Configure Data Direction Registers
    //-------------------------------------------

    ldx #$ff
    stx $dc02                                    // Port A - Output
    inx
    stx $dc03                                    // Port B - Input
    stx ZP_FLAG_NewKeyScanOverflow               // Clear Flag
    rts

    //---------------------------------------------------------------------------------------------
    // Error routines
    //---------------------------------------------------------------------------------------------

!NoPortActivity:
    ldx #$00
    stx ZP_FLAG_NewKeyScanOverflow
    dex
    stx SMC_OldKey1
    stx SMC_OldKey2
    stx SMC_OldKey3
    lda #ERROR.NoActivity
    sec                                          // Can be replaced with a .byte BIT_ABS
    rts

!GameportActivityDetected:
    lda #ERROR.CtrlPortActivity
    sec
    rts

!KeyScanOverflowFlag:
    lda #ERROR.KeyScanOverflowFlag
    sec
    rts


    //---------------------------------------------------------------------------------------------
    // Routine Start
    //---------------------------------------------------------------------------------------------

Keyboard:

    //-------------------------------------------
    // Check for any Port Activity
    //-------------------------------------------

    ldx #$00
    stx $dc00                                    // Connect all Keyboard Rows
    dex
    cpx $dc01                                    // Any activity in any rows?
    beq !NoPortActivity-

    //-------------------------------------------
    // Check 'too many keys detected' flag
    //-------------------------------------------

!:  bit ZP_FLAG_NewKeyScanOverflow
    bne !KeyScanOverflowFlag-

    //-------------------------------------------
    // Check for Control Port #1 Activity
    //-------------------------------------------

    stx $dc00                                    // Disconnect all Keyboard Rows
    cpx $dc01                                    // Only Control Port activity will be detected
    bne !GameportActivityDetected-

    //-------------------------------------------
    // Scan Keyboard Matrix
    // BNE => ZERO = 1 => CARRY = 1
    //-------------------------------------------

    ldy #%11111110
    ldx #%11111101
    lda #%11111011                               // This reduces the amount of rotations needed.
    sty $dc00                                    // Read from Row #7

    ldy $dc01                                    // The trick is to minimize cycles from here;
    stx $dc00                                    // Read from Row #6
    ldx $dc01
    sta $dc00                                    // Read from Row #5
    sty ZP_ScanResult + 7
    stx ZP_ScanResult + 6
    ldy $dc01
    sty ZP_ScanResult + 5
    rol
    sta $dc00                                    // Read from Row #4
    ldx $dc01
    rol
    sta $dc00                                    // Read from Row #3
    ldy $dc01
    stx ZP_ScanResult + 4
    sty ZP_ScanResult + 3
    rol
    sta $dc00                                    // Read from Row #2
    ldy $dc01
    rol
    sta $dc00                                    // Read from Row #1
    ldx $dc01
    rol
    sta $dc00                                    // Read from Row #0
    lda $dc01                                    // To here!

    sty ZP_ScanResult + 2
    stx ZP_ScanResult + 1
    sta ZP_ScanResult + 0

    //-------------------------------------------
    // Check for Control Port #1 Activity (again)
    //-------------------------------------------

    ldx #$ff
    stx $dc00
    cpx $dc01
    bne !GameportActivityDetected-

    //-------------------------------------------
    // Reset Key Scan Buffer
    //-------------------------------------------

    stx ZP_ScanKeyBuffer
    stx ZP_ScanKeyBuffer + 1
    stx ZP_ScanKeyBuffer + 2

    //-------------------------------------------
    // Identify which / how many keys are pressed
    //-------------------------------------------

    lda #MaxKeyRollover                          // This cen go into Y for speed, but will add size
    sta ZP_Temp
    cpx ZP_ScanResult + 7
    bne !KeyInRow7+ ; !Return7:
    cpx ZP_ScanResult + 6
    bne !KeyInRow6+ ; !Return6:
    cpx ZP_ScanResult + 5
    bne !KeyInRow5+ ; !Return5:
    cpx ZP_ScanResult + 4
    bne !KeyInRow4+ ; !Return4:
    cpx ZP_ScanResult + 3
    bne !KeyInRow3+ ; !Return3:
    cpx ZP_ScanResult + 2
    bne !KeyInRow2+ ; !Return2:
    cpx ZP_ScanResult + 1
    bne !KeyInRow1+ ; !Return1:
    cpx ZP_ScanResult + 0
    beq !DoneFindingKeys+

!KeyInRow0:
    ldx #<KeyTable + $38                         // Index into Keyboar Matrix Table
    ldy # !DoneFindingKeys+ - SMC_Return - 1     // Relative Return Address
    lda ZP_ScanResult + 0                        // Fetch Row Scan Value
    bne !ScanRow+                                // Branch Always (Row Value should never be #$00)!

!KeyInRow1:
    ldx #<KeyTable + $30
    ldy # !Return1- - SMC_Return - 1
    lda ZP_ScanResult + 1
    bne !ScanRow+

!KeyInRow2:
    ldx #<KeyTable + $28
    ldy # !Return2- - SMC_Return - 1
    lda ZP_ScanResult + 2
    bne !ScanRow+

!KeyInRow3:
    ldx #<KeyTable + $20
    ldy # !Return3- - SMC_Return - 1
    lda ZP_ScanResult + 3
    bne !ScanRow+

!KeyInRow4:
    ldx #<KeyTable + $18
    ldy # !Return4- - SMC_Return - 1
    lda ZP_ScanResult + 4
    bne !ScanRow+

!KeyInRow5:
    ldx #<KeyTable + $10
    ldy # !Return5- - SMC_Return - 1
    lda ZP_ScanResult + 5
    bne !ScanRow+

!KeyInRow6:
    ldx #<KeyTable + $08
    ldy # !Return6- - SMC_Return - 1
    lda ZP_ScanResult + 6
    bne !ScanRow+

!KeyInRow7:
    ldx #<KeyTable + $00
    ldy # !Return7- - SMC_Return - 1
    lda ZP_ScanResult + 7

    //-------------------------------------------
    // Common Routine for Key Row Scan - Uses SMC
    //-------------------------------------------

!ScanRow:
    stx SMC_KeyTable
    sty SMC_Return
    ldx #$07
!Loop:
    asl
    bcc !FoundKey+ ; !FoundKeyReturn:
    dex
    bpl !Loop-
    bmi SMC_Return: *                            // Branch Always

!FoundKey:
    dec ZP_Temp
    bmi !Shadowing+
    ldy ZP_Temp
    sta ZP_Temp2                                 // Preserve Accumulator
    lda SMC_KeyTable: KeyTable,x                 // Must not cross page!
    sta ZP_ScanKeyBuffer,y
    lda ZP_Temp2
    bcc !FoundKeyReturn-                         // BRA

    //-------------------------------------------
    // ERROR - Key Shadowing
    //-------------------------------------------

!Shadowing:
    lda #ERROR.Shadowing
    sec
    rts

    //-------------------------------------------
    // ERROR - Too Many Keys
    //-------------------------------------------

!KeyScanOverflow:
    dec ZP_FLAG_NewKeyScanOverflow
    lda #ERROR.KeyScanOverflow
    sec
    rts

    //---------------------------------------------------------------------------------------------
    // Done Scanning for pressed keys.
    //
    // Valid keys stored in ZP_ScanKeyBuffer:
    //   ZP_ScanKeyBuffer + 2 = 1st Key
    //   ZP_ScanKeyBuffer + 1 = 2nd Key
    //   ZP_ScanKeyBuffer + 2 = 3rd Key
    // Quantity of pressed keys in ZP_Temp:
    //   ZP_Temp = #$02 => 1 key pressed
    //   ZP_Temp = #$01 => 2 keys pressed
    //   ZP_Temp = #$00 => 3 keys pressed
    // There is no danger of keys stored outside buffer range
    // and there is no danger of ZP_Temp being outside 0 - 2 range.
    //---------------------------------------------------------------------------------------------

!DoneFindingKeys:

    //---------------------------------------------------------------------------------------------
    // Flag Non-Alphanumeric keys
    //---------------------------------------------------------------------------------------------

    lda ZP_ScanResult + 6
    eor #$ff
    and #%10000000                               // ARR is an issue due to CARRY
    lsr                                          // Clears CARRY
    sta ZP_NonAlphaFlagY
    lda ZP_ScanResult + 0
    eor #$ff
    and #%10100100                               // RUN STOP - C= - CTRL
    ora ZP_NonAlphaFlagY
    sta ZP_NonAlphaFlagY
    lda ZP_ScanResult + 1
    eor #$ff
    and #%00011000                               // Right SHIFT - CLR HOME
    ora ZP_NonAlphaFlagY
    sta ZP_NonAlphaFlagY
    lda ZP_ScanResult + 7                        // The rest
    eor #$ff
    sta ZP_NonAlphaFlagX

    //-------------------------------------------
    // Check how many keys are pressed;
    //   ZP_Temp = #$02 => 1 key pressed  {0}
    //   ZP_Temp = #$01 => 2 keys pressed {1}
    //   ZP_Temp = #$00 => 3 keys pressed {2}
    // CARRY is Clear here
    //-------------------------------------------

    lda #$03
    sbc ZP_Temp
    tax                                          // X = many keys are being pressed (0, 1 or 2)

    //-------------------------------------------
    // Check if the key(s) were present last scan
    // and check for simultaneous keypress.
    //-------------------------------------------

    ldy #$01
    sty ZP_Temp
    iny                                          // check 1st key
!:  lda ZP_ScanKeyBuffer,y
    cmp SMC_OldKey1: #$ff
    beq !InLastScan+
    cmp SMC_OldKey2: #$ff
    beq !InLastScan+
    cmp SMC_OldKey3: #$ff
    beq !InLastScan+

        dec ZP_Temp                              // Counter/Flag for too many keys in one scan
        bmi !KeyScanOverflow-                    // Error stuff for simult. pressed keys
        sta SMC_NewAlphaKey                      // Store key for return

!InLastScan:
    dey
    dex
    bpl !-

    //-------------------------------------------
    // Check if there are ANY new keys pressed
    //-------------------------------------------

    ldy SMC_RepeatTimer1: #$00
    lda ZP_Temp
    beq !Exit_NewKey+                           // New key should happen more rarely (so no BNE).

        //---------------------------------------
        // No new alphanumeric keys detected,
        // will the held key be repeated?
        //---------------------------------------

        txa                                      // X = #$ff from loop above.
        bit ZP_RepeatFlag
        bmi !Exit_NoRepeatFlag+                  // TXA can be removed with designated exit routine

            //-----------------------------------
            // Are there any alpha-numeric keys?
            //
            // Do before timer is decreased!
            //
            // There must be a better way...
            //-----------------------------------

            lda ZP_ScanKeyBuffer
            and ZP_ScanKeyBuffer + 1
            and ZP_ScanKeyBuffer + 2
            cmp #$ff
            beq !Exit_NoAlphaKeys+               // If no alpha keys pressed, Reset Timer & Exit!

                //-------------------------------
                // Check timer
                //-------------------------------

                txa                              // X = #$ff from loop above.
                dec ZP_RepeatTimer
                bne !Exit_TimerNotZero+

                    //---------------------------
                    // Timer = 0:
                    // Reset timer to value #2 &
                    // Exit and return last key
                    //---------------------------

                    ldy SMC_RepeatTimer2: #$00
//                    jmp !Exit_RepeatKey+        // Uncomment to skipp buffer update - Speed vs. Size

    //-------------------------------------------
    // New Key - Update old values.
    //-------------------------------------------

!Exit_NewKey:                                    // Reset Timer1 & A = New Key
    ldx ZP_ScanKeyBuffer + 2
    stx SMC_OldKey1
    ldx ZP_ScanKeyBuffer + 1
    stx SMC_OldKey2
    ldx ZP_ScanKeyBuffer + 0
    stx SMC_OldKey3

    //-------------------------------------------
    // Return new key or repeat key
    //-------------------------------------------

!Exit_RepeatKey:                                 // Reset Timer2 & A = Last Key
    lda SMC_NewAlphaKey: #$00

    //-------------------------------------------
    // Reset timer to Value #1
    //-------------------------------------------

!Exit_NoAlphaKeys:                               // Reset Timer1 & A = #$ff
    sty ZP_RepeatTimer

    //-------------------------------------------
    // Common Exit for Alpha, Non-Alpha and
    // Repeat keys
    //-------------------------------------------

!Exit_NoRepeatFlag:
!Exit_TimerNotZero:
    ldx ZP_NonAlphaFlagX
    ldy ZP_NonAlphaFlagY
    clc
    rts


    //---------------------------------------------------------------------------------------------
    // Must not cross page boundary
    //---------------------------------------------------------------------------------------------

    .pc = * "Table"

    .errorif [$100 - [* & $ff]] < 64, "Keyboard Lookuptable crosses page boundary"

KeyTable:
    .byte $ff, $ff, $ff, $ff, $ff, $ff, $ff, $ff  // CD F5 F3 F1 F7 CR RT ID
    .byte $33, $17, $01, $34, $1a, $13, $05, $ff  //  3  W  A  4  Z  S  E LS
    .byte $35, $12, $04, $36, $03, $06, $14, $18  //  5  R  D  6  C  F  T  X
    .byte $37, $19, $07, $38, $02, $08, $15, $16  //  7  Y  G  8  B  H  U  V
    .byte $39, $09, $0a, $30, $0d, $0b, $0f, $0e  //  9  I  J  0  M  K  O  N
    .byte $2b, $10, $0c, $2d, $2e, $3a, $00, $2c  //  +  P  L  -  .  :  @  ,

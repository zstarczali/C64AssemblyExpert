====== SetCharMode ======

Set Character Set Mode (reset bit #5 of $d011).

| SYNTAX:     | :SetCharMode |
| EXAMPLE:    | :SetCharMode |
| PARAMETERS: |  N/A         |

<code>
    .pseudocommand SetChar {
        lda #%0010000000000000
        trb $d010
    }
</code>

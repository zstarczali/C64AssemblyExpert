====== BitMode8 ======

Pseudocommand to set the Accumulator and X/Y Index registers to 8 bit mode on the 658C16.

| SYNTAX:        | BitMode8 |
| EXAMPLE:       | BitMode8 |
| PARAMETERS:    | N/A      |

<code>
    .pseudocommand BitMode8 {
        sep #%00110000
    }
</code>

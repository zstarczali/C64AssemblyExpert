# Forrasok hozzaadasa

Itt gyujtsd a C64 assembly agent forrasait.

## Javasolt szerkezet

- `books/`: konyvek, OCR-ek, jegyzetek
- `pdfs/`: PDF dokumentaciok
- `urls/`: URL listak, mentett webes anyagok
- `notes/`: sajat jegyzetek
- `code/`: peldaprogramok es referenciakod

Aktualis allapot:
- a bekerult PDF-ek a `pdfs/` mappaba lettek rendezve
- az elso tematikus index a `knowledge/index-template.md` fajlban van

## Mit erdemes ide tenni

- C64 Programmer's Reference Guide
- Mapping the C64
- VIC-II dokumentacio
- SID dokumentacio
- CIA / 6526 leirasok
- assembler manualok
- sajat demok, tesztkodok

## URL-ek kezelese

Az URL-eket teheted egy sima markdown fajlba vagy kulon text fajlokba.

Peldak:
- `urls/reference-sites.md`
- `urls/kernal-routines.md`
- `urls/sprite-techniques.md`

Aktualis URL gyujtemeny:
- `urls/reference-sites.md`

## PDF-ek kezelese

Minden PDF melle erdemes egy rovid leiro fajlt tenni:
- mi a tema
- mennyire megbizhato
- mely fejezetek erdekesek

Pelda:
- `pdfs/mapping-the-c64.pdf`
- `pdfs/mapping-the-c64.notes.md`

## Konyvek kezelese

Ha van digitalizalt vagy OCR-ezett anyag, bontsd fel temakra, ha lehet.
Ez sokkal jobban keresheto, mint egyetlen nagy dokumentum.
